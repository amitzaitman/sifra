# sifra

משחקי חשבון לילדי בית ספר יסודי, בעברית, לטלפון ולטאבלט. מתחילים בכיתות א–ב
וגדלים משחק אחרי משחק עד כיתה ו.

אתר סטטי ב-GitHub Pages, שקט לגמרי, בלי שרת ובלי שלב בנייה.

המצב: אבן הדרך הראשונה. יש מעטפת ושלושה משחקים, מסגרת עשר, מאזניים וסיפורים (המשחק השלישי, מ-2026-10-30), עם
בדיקות אוטומטיות ו-CI. כל מיזוג ל-main מתפרסם מיד ב-GitHub Pages. המשחקים עדיין בפיתוח, והקישור עוד לא נשלח
לילדים.
