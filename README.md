# sifra

משחקי חשבון לילדי בית ספר יסודי, בעברית, לטלפון ולטאבלט. מתחילים בכיתות א–ב
וגדלים משחק אחרי משחק עד כיתה ו.

אתר סטטי ב-GitHub Pages, שקט לגמרי, בלי שרת ובלי שלב בנייה.

המצב: אבן הדרך הראשונה. יש מעטפת ושני משחקים, מסגרת עשר ומאזניים, עם בדיקות אוטומטיות ו-CI. משחק עולה לאוויר
אחרי בדיקה ידנית באייפון, שנרשמת ב[יומן הבדיקות במכשיר](docs/device-checks.md).
